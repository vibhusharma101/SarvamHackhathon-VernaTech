A language gap only means something if it's bigger than the noise.

Vernatech scores the same technical answer once in English, once in the candidate's own language. If the scores differ, is that real bias — or is it just how much the scorer's own judgment wobbles from run to run anyway? The real code behind it

Two functions, read straight from the repo. This page's JS is a line-for-line port of both.

api/app/services/aggregate.py — turns 3 raw runs into one score
def aggregate(runs: list[RunResult]) -> AggregatedResult:
    scored = [r for r in runs if r.status == "scored"]

    # majority insufficient -> the criterion itself is insufficient
    if len(scored) < 2:
        return AggregatedResult(status="insufficient_evidence", score=None,
                                 low_consistency=len(scored) == 1)

    vals = sorted(r.score for r in scored)
    median = vals[len(vals)//2] if len(vals) % 2 else ceil((vals[0]+vals[1])/2)
    low_consistency = (max(vals) - min(vals)) >= 2 or len(scored) == 2
    return AggregatedResult(status="scored", score=median, low_consistency=low_consistency)
api/app/services/stats.py — is the English/vernacular gap real?
def compute_harness_stats(english_scores, vernacular_scores, ...):
    # Rule 1: a criterion refused (None) in EITHER language is excluded
    diffable = [c for c in common if english_scores[c] is not None
                and vernacular_scores[c] is not None]
    diffs = [abs(english_scores[c] - vernacular_scores[c]) for c in diffable]
    competence_mad = sum(diffs) / len(diffs)          # Rule 1
    max_observed_gap = max(diffs)                      # Rule 2: per-criterion, not the mean

def noise_verdict(stats):
    pooled_variance = (stats.english_run_variance + stats.vernacular_run_variance) / 2
    if stats.competence_mad <= pooled_variance:
        return "language difference is within scorer noise"
    return "language difference exceeds scorer noise — disclose plainly"   # Rule 3
The aha

The harness doesn't ask "did the score change?" — every LLM judge wobbles run to run even scoring the same language twice. It asks "did it move more than it already wobbles on its own?" A gap smaller than that is just the instrument's hand shaking. Only a gap bigger than its own noise floor gets called bias.

Glossary

Competence MAD

Mean of |English score − vernacular score| across every criterion scored in both languages.

Excluded criteria

A criterion where either language came back "insufficient evidence" isn't diffable — it's dropped from MAD entirely, not treated as a zero gap.

Run variance

Statistical variance across the 3 self-consistency runs for one criterion, averaged across all criteria — the scorer's own baseline jitter.

Low consistency

Flagged when the 3 runs spread by 2+ points, or when only 2 of 3 even agreed on scoring at all.

Recap

  • Every criterion is scored 3× independently, in each language — that's the noise floor.
  • MAD only ever compares criteria both languages actually managed to score.
  • A gap is only "bias" if it's bigger than the scorer's own run-to-run wobble.
  • Nothing here is hidden after the fact — the harness discloses the verdict either way.
